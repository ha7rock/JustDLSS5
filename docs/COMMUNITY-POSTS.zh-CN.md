# 首轮社区发布材料

以下为帖子草稿，尚未向任何社区发送。链接在公开预发布上线后可直接使用。截图使用示例游戏数据，不能当作游戏兼容性证据。

## 主帖

**标题：**【开源／测试版】JustDLSS5：用中文界面管理游戏画面组件

做了一个 Windows 桌面工具 **JustDLSS5**，把游戏扫描、组件安装、参数配置和卸载整理到一个界面里，支持中文和英文。

安装核心沿用 **DLSS5-Autopilot v1.7.1**，我们主要维护独立的 Qt 前端和使用流程。感谢上游及各个组件作者。

目前可以扫描本地游戏、手动添加目录、预览安装变更、选择组件配置，以及管理安装和卸载。下载 ZIP 完整解压即可运行，不需要自己装 Python。

这次放出的是玩家测试版，想先收集实际使用的问题：有没有游戏识别错了、选项不好理解、界面显示不全，或者某个游戏安装后出现异常。反馈时请带上游戏版本、平台、显卡驱动、配置和复现步骤；应用里有“反馈问题”入口。

请先用离线单机游戏测试，并备份存档和重要配置。反作弊警告不是完整名单；不要用于联网或反作弊游戏。它是社区工具，与 NVIDIA 无关，也不承诺任意游戏都能使用。

## 发布节奏

先在维护者已有账号、允许发布原创工具的一个社区发主帖，收集一轮反馈后修复高频问题，再考虑第二个社区。实际发帖前核对该板块规则；不跨板重复铺帖、不使用未经实测的性能数字、不把示例截图说成实测。

优先记录有效反馈数量、阻断启动的问题、扫描错误和卸载恢复问题。第一轮目标是发现并修复问题，不以 Star 数量替代可用性。
