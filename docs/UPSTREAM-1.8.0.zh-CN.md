# v1.8.0 检查与接入

日期：2026-09-10。上游发布于 00:47:49 UTC。

- 升级前：v1.7.3 / `f26717ad3369e93f9de3972734132402ec8a4444`。
- 固定提交：`99377baace9c9358feeb5b5275561bbb54840def`。
- 产品版本：JustDLSS5 0.2.6；核心与 CLI 保持上游源码，Qt 适配留在 frontend。

## 继承与适配

继承 32 位 Vulkan 层独立名称与旧层重写、下载重试、7-Zip 回退、归档及安装记录路径校验、Steam 下载中 / 残留目录过滤、诊断规则和 NVIDIA 官方运行时来源。

Qt 接入 Options.dlssd，默认保留游戏文件，仅在检测到已有 RR 且路线支持时传入替换请求；显示备份、启动器覆盖和反作弊提醒。面板按键设置使用上游键值，安装提示按所选键显示。驱动、HDR 和非 NVIDIA 显卡信息在后台读取，路线变化不查询磁盘或注册表。

新增 frontend/session.py 负责运行诊断衔接。Windows 记录与最新日志比较时间，旧崩溃不改写本次成功结果。目标帧率建议使用已安装路线和配置，按路线筛选历史记录。只有用户明确点击应用才写配置；写前复核安装与原数值，写后重新读取验证，避免上游静默写入失败导致界面误报。

社区报告入口只读取上游汇总，不上传信息。本项目保留自己的 GitHub Issue 表单，启动结果、问题、步骤与截图等已有必填项；未引入上游的 Tk 反馈对话框及上游 Issue 汇总工作流，不将 JustDLSS5 问题自动发到上游。

## 依赖与边界

新增核心模块 autotune、community、wincrash、reportui，Qt 不依赖 Tk。无新增需随包分发的第三方依赖。Windows 事件查询有上游超时；7-Zip 为系统已有程序的可选回退，不随包提供。社区汇总读取上游 raw GitHub 文件。DLSS / DLSSG / RR 从 NVIDIA 仓库固定发布标签下载，DLSSNR 仍为适配显卡的社区来源。

自动维护没有扫描、安装、卸载或调节任何真实游戏，也未注册 Vulkan / OpenXR 层。
