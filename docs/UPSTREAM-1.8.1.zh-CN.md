## 行为与接口

继承图形接口检测排除跨 API 的崩溃库、正式 EXE 优先、扫描与缓存按 EXE 去重并保留安装 / 手动 API 状态，以及嵌套运行时目录的受限搜索。

下载对 ZIP / 7z / Windows 二进制执行内容检查；错误缓存重取，不将代理 HTML 页面继续缓存。MFG 在写文件前验证两个归档，已知来源变化和下载问题改为可选组件警告。Bridge 配置加 keep 标记，并在找到原生 DLSS 后清除旧的 synth_after。OptiScaler 开启文件日志、保留用户明确的日志级别，关闭不适用于神经渲染分支的主线更新提示。

Qt 向 driver_warning 传入实际可选路线。仅在可选时提示 Standalone；Standalone 不再套用 RenoDX 的故障结论。显示启用 FSR / XeSS 的游戏内设置前提，即使当前路线通过兼容性检查也不会隐藏。原窗口布局、滚轮防误触、反馈入口保持不变。

没有复制上游 Tk 页面、导航、样式或共享报告自动关闭工作流。本产品继续使用自己的界面和 Issue 表单。上游 selfupdate 的修复保留在核心中，本产品的应用更新仍为下载入口，不宣称自动替换 EXE。

## 依赖与验证

无新增需随包分发的依赖；MFG 来源解析更宽容，仍在运行时按用户操作下载。未安装游戏组件、注册图形层或修改真实游戏目录。

- 新增 Bridge 配置保留、日志级别、缓存去重、试用 EXE、错误缓存重取、崩溃库识别和 MFG 写前拒绝测试；文件仅为临时夹具。
- 发布前执行 Windows EXE 启动和证书检查，由同一提交的 GitHub 构建生成发行材料，并核对摘要与构建提交。

未运行上游完整测试套件或真实游戏 / VR 测试；不新增游戏兼容承诺。缓存按引擎版本失效，升级后可重新扫描恢复游戏列表。
