# 诊断信息展示

`frontend/session.py` 保留上游报告的结构化字段与原始文本，`frontend/diagnostic_view.py` 负责显示。安装检查与运行分析使用同一视图，应用建议仍通过原有校验与用户确认执行。

`frontend/diagnostic_text.py` 是固定版本引擎的展示适配层：完整文本匹配固定文案，完整正则匹配动态模板。捕获的路径、名称、版本、错误码原样插入。不要对整段日志做单词替换，也不要从英文关键词重新推断诊断严重程度。

- 异常和注意项先显示；提示独立成组；通过项默认折叠。组内维持上游顺序，未知等级仍可见。
- 已知结论与标题显示中文；关键问题可附简明下一步。未翻译的详细说明提供明确的原文展开入口。
- 未匹配的标题或结论显示原文及说明，不能丢弃或伪装为成功。外部内容不当作已翻译的程序提示。
- 原始报告单独显示、完整复制，不自动上传。路径和日志内容始终作为纯文本显示。
- 原始报告中的时间只作为关联线索；近期崩溃不等同于已确定原因，较早记录不能否定本次运行。

同步引擎时运行 `test_upstream.py`：文案覆盖测试会检查固定诊断标题与直接赋值的固定结论，新增消息需同时适配。动态、拼接文案和详细说明还需人工审查；固定文案测试不代表所有日志已翻译。

`test_ui.py` 检查中英文切换、异常/未知等级可见、原文复制、长字符串窄窗口、通过项展开、后台检查反馈和取消调整不写配置。
