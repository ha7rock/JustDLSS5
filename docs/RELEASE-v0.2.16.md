# JustDLSS5 v0.2.16 · 玩家测试版

本版将海报墙和独立游戏页与 Autopilot v2.0.5 引擎合并交付。

- 游戏库支持封面、列表、搜索、平台筛选、收藏和排序。
- 封面接入上游 Epic、Xbox 和 Steam 新资源地址；仍可手动指定和重试。未匹配或商店未提供的封面仍可能缺失。
- 在游戏页启动游戏，显示请求结果；应用保持打开时，可在游戏退出后查看运行诊断。
- 诊断、运行分析、组件版本、DLSS 文件管理及自动尝试改为页内显示；返回游戏库保留当前位置。

下载 Windows x64 ZIP，完整解压后运行 JustDLSS5.exe。此为社区测试版，与 NVIDIA 无关。仅用于离线游戏；反作弊游戏不应安装注入组件。

发行包包含第三方许可、源码获取说明；对应源码、SHA256SUMS 和 BUILD-INFO 随本 Release 提供。自动化验证覆盖界面和适配行为，不能保证所有游戏、平台或运行环境兼容。
