# JustDLSS5 v0.2.18 · 玩家测试版

引擎更新至 Autopilot v2.0.7（f1034a8443786a75b0132d8e162d29849a76d4d3）。保留现有海报墙、独立游戏页和启动后诊断。

- Bridge 诊断读取实际输出帧数、帧率与停止原因，提供中文结论及可复制的原始日志片段。输出帧数不代表神经渲染画面效果已得到验证。
- 自备补帧文件支持上游允许的替代 DLL 名称；新增清除缓存入口，操作影响所有游戏，已安装副本在重新安装或卸载时移除。
- 增加 Janblade OptiScaler 分支（实验性，未实机验证）。
- 继承锁定文件回滚、32 位辅助进程诊断、原生补帧备份识别和组件缺失检查修复。
- 安装记录无法保存时停止批量更新并展示恢复说明，避免继续修改其他游戏。

完整解压 Windows x64 ZIP 后运行 JustDLSS5.exe。发行附对应源码、SHA256SUMS、BUILD-INFO、第三方许可及源码获取说明。只用于离线游戏，避免反作弊环境；社区项目，与 NVIDIA 无关。

本轮验证使用离线样本和打包启动检查，没有安装真实游戏组件；新增补帧及 Janblade 分支的游戏效果仍需玩家反馈。
