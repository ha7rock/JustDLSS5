## 接入检查

接口检查覆盖 103 项属性与前端调用签名。新的 quick_scan、bitness_override / set_bitness_override、detect(driver=...) 已在 Qt 适配；架构未知时通过 check_supported 禁止安装。首次无有效缓存执行完整扫描，之后增量扫描，用户可明确要求完整扫描。保留手动选择程序与残留目录过滤。

继承重复安装保留原文件备份、原子写入安装记录及游戏库、MFG 复用已有 ASI 加载器、磁盘满与中止原因记录、启动器和 Unreal 图形接口识别修复。新版诊断识别 elapsed 耗时、空日志、编译中退出和插件已加载但效果未运行等情况。补齐中文标题与结论，动态值保持原样。Windows 崩溃证据覆盖未运行结论时校验目录边界，已有有效日志的驱动模块崩溃仍正常展示。

独立窗口路线的驱动推荐仅针对无原生 DLSS 的游戏，已有安装路线不变。ShortFuse 的驱动兼容性不确定提示与 RenoDX 区分。Remix runtime 替换控件本产品已有，无需再增加。上游 Tk 高缩放布局不替换本产品 Qt 界面；上游维护钩子不导入。

## 下载、依赖和边界

组件发行信息增加 github.com 网页回退；TLS 错误按原因解释。没有新增随包分发依赖。7z 解压失败时在运行时下载固定 7zr.exe，执行前必须匹配 SHA-256；错误摘要不得执行。没有改动实际游戏目录、注册 Vulkan 层或自动替换用户已修复的组件。

应用自己的版本检查仍依赖 GitHub API，且当前提供下载入口而非自动替换程序；不能把上游核心 updater 的改进视为本产品已实现自动更新。

## 验证与后续迭代

103 项回归和 6 组 INI 检查。新增覆盖完整/增量扫描切换、残留程序过滤、受保护架构选择及安装门槛、驱动推荐保留已安装路线、重复安装再卸载恢复原文件、错误哈希拒绝执行，以及空日志与 Windows 崩溃记录冲突。文件写入仅在临时测试目录进行。发布使用同一提交的 Windows CI 构建，检查包内版本、许可、构建信息与摘要。

没有执行真实游戏、Game Pass 或 VR 测试，不增加兼容性承诺。

后续可独立迭代：产品更新检查的 API 失败回退与可恢复安装器；游戏专属注意事项的中文展示；插件浮层快捷键冲突检查及明确的用户应用操作。不能在后台修改游戏配置来实现这些体验。
